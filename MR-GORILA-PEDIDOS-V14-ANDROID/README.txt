MR. GORILA PEDIDOS V14 - PROYECTO ANDROID INDEPENDIENTE

Este proyecto es separado de MR. GORILA Notas e Inventario.
Incluye el HTML original MR_GORILA_PEDIDOS_V14_SALDOS_Y_FECHA.html dentro de:
app/src/main/assets/index.html

Aplicación:
- Nombre: MR. GORILA PEDIDOS V14
- Identificador: com.mrgorila.pedidos.v14
- Versión: 14.0
- WebView con JavaScript y almacenamiento local activados.
- Se añadió soporte inicial para la ventana emergente usada por la lista de surtido y el servicio de impresión Android.

COMPILAR CON GITHUB:
1. Sube el contenido de esta carpeta al repositorio nuevo MR-GORILA-PEDIDOS-V14.
2. En GitHub abre Actions.
3. Selecciona "Compilar MR. GORILA PEDIDOS V14".
4. Pulsa "Run workflow".
5. Al terminar, entra al resultado y descarga el artefacto MR-GORILA-PEDIDOS-V14-APK.

IMPORTANTE:
- No subir este proyecto al repositorio de Notas e Inventario.
- El APK aún debe compilarse y probarse en un teléfono Android.
- Los datos de pedidos se guardan en el almacenamiento local de la app. Antes de desinstalar o borrar datos, exporta un respaldo desde la aplicación.
- Los avisos del HTML original usan Notification del navegador; su funcionamiento en WebView Android requiere adaptación y prueba adicional.
